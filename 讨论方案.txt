
Q:刷交易量给返点的交易所或标的

A:目前通过合法合规的“提供流动性（Maker 挂单）”或达到做市商（MM）级别来获取手续费返点（负费率 / Maker Rebate），主要集中在加密货币衍生品/现货交易所、去中心化预测市场以及美股/期权电子做市商通道。
以下按市场类型整理目前提供返点机制的平台与常见标的：

1. 加密货币交易所（Maker 负费率与做市商返佣）

主流加密货币交易所通常采用 Maker-Taker 费率模型，对挂单提供流动性的做市商或高级 VIP 账户给予负费率返点：
• 头部中心化交易所（CEX）： 如 Binance（币安）、OKX（欧易）、Bybit 等。当 30 天交易量达到做市商（MM1-MM3）或高阶 VIP 门槛时，U 本位/币本位合约及部分现货交易对的 Maker 费率会降至 -0.005% 至 -0.015%（即每成交 100 万美元，平台倒贴 50～150 美元）。
• 二线与低费率交易所： 如 MEXC、KuCoin、Gate.io 等，部分平台对持仓平台币（如 MX、KCS）或挂单做市提供阶梯式负费率返还，且门槛通常低于一线大所。
• 去中心化永续合约所（Perp DEX）： 如 Hyperliquid、dYdX 等链上订单簿协议，常设有做市商流动性激励或基于交易量占比的 Maker 返点池。
• 主流刷量标的： 通常选择深度极好、买卖点差（Spread）极小、盘口波动平稳的头部币种，例如 BTC/USDT、ETH/USDT 永续合约，或 USDC/USDT、FDUSD/USDT 等稳定币交易对（部分平台稳定币对免收 Taker 费，但一般不计入 VIP 交易量统计）。

2. 预测市场（事件合约）

• Polymarket： 针对符合条件的流动性提供者（月交易量达到 20 万美元以上），在加密货币相关预测市场中提供所撮合 Taker 手续费 3% 至 15% 的 Maker 返点（注意：组合预测订单通常不计入返点）。

3. 美股与美股期权（流动性返点 / PFOF）

在传统金融市场中，通过普通零售券商无法拿到手续费返点，但机构账户或专业直连通道（DMA）可以通过向交易所提供流动性获得返佣：
• 交易所通道： 纳斯达克（Nasdaq）、纽交所（NYSE Arca）、Cboe（BZX/EDGX）等采用“Maker-Taker”定价模型的交易所，对在盘口挂单（Add Liquidity）并成交的指令提供每股约 $0.0015 至 $0.0030 的返点；部分期权交易所对做市商也有按张计算的流动性返还。
• 接入方式： 需要通过支持自定义路由（Smart Routing / Direct Market Access）的机构级经纪商（如 Interactive Brokers 盈透证券 的阶梯式费率结构，部分交易所的 Add Liquidity 返点会直接抵扣甚至超过单边佣金）。
• 常见标的： 流动性极高、价差固定为 1 美分（$0.01）且成交密集的 ETF 或大盘股，如 SPY、QQQ、IWM、NVDA、AAPL 等。

核心风险与合规提示

1. 禁止自成交（Wash Trading）： 无论是传统证券还是加密货币交易所，使用关联账户“左手倒右手”对敲刷量均属于严重的违规/市场操纵行为，一经风控系统识别，会导致没收返点、冻结资金甚至永久封号。合法获取返点必须依靠高频做市策略（双边挂单与真实对手盘成交）。
2. 盘口逆向选择风险（Adverse Selection）： 做市挂单虽然能赚取微薄的返点，但一旦市场出现单边急涨或急跌，挂单被瞬间击穿产生的库存亏损（Inventory Risk）往往远大于返点收益。
3. 规则动态调整： 各大交易所会定期调整做市商考核标准、净手续费计算口径（例如扣除返佣后的净额计算）以及豁免交易对列表。

二、 GLFTmm 适配 Polymarket 的 4 项核心代码改造

Polymarket 是基于 Polygon 链下撮合、链上结算的 CLOB（中央限价订单簿），交易的是 YES / NO 二元期权份额（价格严格限制在 $0.01 ~ $0.99，无杠杆）。直接把永续合约的 GLFTmm 搬过去会因为边界效应和资金效率问题失灵，建议做以下定向改造：

1. 数学内核从“价格空间”映射到“Logit（对数几率）空间”

• 痛点： GLFTmm 假设资产价格服从算术布朗运动且无上下界；但 Polymarket 价格在 0.50 附近波动率最大，在 0.05 或 0.95 附近波动率天然收敛至 0，且不能超过 1.00。
• 改造方案： 在 shared/glft_engine/ 中增加一层 Logit 变换：
\(x=\ln \left(\frac{P}{1-P}\right)\)
把 \([0.01, 0.99]\) 的概率价格映射到 (-∞, +∞) 的无界对数几率空间，在这个空间里运行你原有的 Stationary GLFT 求解器 算出的最优报价 \(x^a, x^b\)，最后再通过 Sigmoid 函数 \(P = \frac{1}{1 + e^{-x}}\) 还原回盘口报价并对齐 Tick Size（通常为 0.01 或 0.001）。这样能完美解决临近 0/1 边界时的报价畸变。

一、 核心桥梁：用“跨市场先验模型”替代盘口自身中间价

在永续合约中，你的模型直接围绕当前盘口中间价 \(P_{\text{micro}}\) 展开；但在 Up/Down 盘（例如“BTC 15分钟涨跌”），Polymarket 自身的盘口是滞后的，真正的“锚”是 Binance/OKX 的 BTC 现货实时价格 \(S_{t}\) 与 开盘基准价 S₀。

1. 实时理论公允概率（Fair Probability \(P_{\text{fair}}\)）计算

在你的 shared/glft_engine/ 前面加一层 二元数字期权定价器（Binary Black-Scholes）：
假设当前距离该局 Up/Down 结算还剩 τ = T - t 秒，BTC 实时年化波动率为 \(\sigma _{S}\)，当前价为 \(S_{t}\)，本局开盘价为 S₀，则 Up 获胜的理论公允概率为：
\(P_{\text{fair}}(S_{t},\tau )=\Phi \left(\frac{\ln (S_{t}/S_{0})-\frac{1}{2}\sigma _{S}^{2}\tau }{\sigma _{S}\sqrt{\tau }}\right)\)
(其中 Φ 为标准正态分布累积函数。在零漂移短周期内，可简化为 \(\Phi\left(\frac{\ln(S_t/S_0)}{\sigma_S \sqrt{\tau}}\right)\))
• 这解决了一个核心问题： 当 BTC 现货在 Binance 刚刚跳动 0.05% 时，你的模型立刻算出新的 \(P_{\text{fair}}\)，在 Polymarket 的套利者冲过来吃单前，你的改单指令已经发出，彻底避免被“信息差”收割。

2. 概率空间波动率 \(\sigma _{P}\) 的动态推导（适配 GLFT/A-S）

GLFTmm 需要输入标的波动率 σ 来计算半利差 δ 和库存风险。对于 Up/Down 盘，概率价格的瞬时波动率 \(\sigma _{P}\) 并不是常数，而是由期权 Delta (\(\Delta _{B}\)) 放大决定的：
\(\sigma _{P}(t)=\underbrace{\frac{\phi (d_{2})}{S_{t}\cdot \sigma _{S}\sqrt{\tau }}}_{\text{二元期权 }\Delta _{B}}\cdot (S_{t}\sigma _{S})=\frac{\phi (d_{2})}{\sqrt{\tau }}\)
(其中 φ 是标准正态概率密度函数，\(d_2 = \frac{\ln(S_t/S_0)}{\sigma_S \sqrt{\tau}}\))
• 直观物理意义：
	• 当 \(S_t \approx S_0\)（即概率在 50% 附近）且剩余时间 τ 变小时，\(\frac{1}{\sqrt{\tau }}\) 急剧变大，\(\sigma _{P}\) 飙升。
	• 把这个动态算出的 \(\sigma_P(t)\) 直接喂给你的 GLFTmm 求解器，模型会自动在临近结算、Gamma 风险最大时自动拉宽价差（δ 增大）并加重库存惩罚（\(q \cdot \gamma \cdot \sigma_P^2\)），完全不需要写死硬编码规则！

二、 专门针对“中间价流动性奖励”的报价约束改造

你提到之前手动挂在中间价附近即便不成交也有奖励，这是因为 Polymarket 的 Liquidity Rewards 采用二次方衰减评分公式：
\(\text{Score}\propto \left(1-\frac{|{}P_{\text{quote}}-P_{\text{mid}}|{}}{\text{MaxSpread}}\right)^{2}\times \text{Size}\)
只有当你的挂单价与盘口中间价 \(P_{\text{mid}}\) 的距离小于 MaxSpread（通常为 1¢～3¢）时，得分才大于 0。
为了兼顾 GLFT 防御 与 中间价奖励吃满，需要在你的报价输出层加一个“奖励区间钳位器（Reward Clamping）”：
1. 双边对称基准（Q-Score 规则）： Polymarket 奖励机制对单边挂单惩罚极重（单边得分要除以 3），必须同时挂出 Buy YES 和 Buy NO（等价于双边报出 Bid 和 Ask）。

import asyncio
import json
import math
import time
from collections import deque
import websockets


class OKXSpotOracle:
    """
    OKX 公共行情先验引擎 (无需 API Key / 交易权限)
    职责：
    1. 订阅 OKX 公共频道 bbo-tbt (逐笔最优买卖价) 获取毫秒级中间价
    2. 维护滑动窗口计算实时年化波动率 sigma_S (用于二元期权定价)
    3. 计算短周期价格冲击 (Toxic Jump)，触发 Polymarket 紧急撤单保护
    """

    WS_URL = "wss://://okx.com"

    def __init__(self, inst_id: str = "BTC-USDT", vol_window_sec: int = 300):
        self.inst_id = inst_id
        self.vol_window_sec = vol_window_sec

        # 实时价格状态
        self.best_bid: float = 0.0
        self.best_ask: float = 0.0
        self.mid_price: float = 0.0
        self.last_update_ts: float = 0.0

        # 用于计算波动率的采样队列: 存储 (timestamp, log_price)
        self.price_history: deque = deque()
        # 默认初始年化波动率 (例如 BTC 50%)
        self.annual_vol: float = 0.50

        # 毒性跳变检测 (1秒内涨跌幅超过阈值则标记为毒性冲击)
        self.short_term_prices: deque = deque()
        self.is_toxic_shock: bool = False
        self.toxic_shock_until: float = 0.0

    async def start(self):
        """启动后台 WebSocket 断线重连循环"""
        while True:
            try:
                async with websockets.connect(
                    self.WS_URL, ping_interval=20, ping_timeout=10
                ) as ws:
                    sub_msg = {
                        "op": "subscribe",
                        "args": [{"channel": "bbo-tbt", "instId": self.inst_id}],
                    }
                    await ws.send(json.dumps(sub_msg))
                    print(f"[OKXOracle] 已连接并订阅公共行情: {self.inst_id}")

                    async for raw_msg in ws:
                        if raw_msg == "pong":
                            continue
                        data = json.loads(raw_msg)
                        if "data" in data and len(data["data"]) > 0:
                            self._on_bbo_tick(data["data"][0])

            except Exception as e:
                print(f"[OKXOracle] 连接断开 ({e})，2秒后重连...")
                await asyncio.sleep(2)

    def _on_bbo_tick(self, tick: dict):
        """处理逐笔 BBO 数据"""
        now = time.time()
        bids = tick.get("bids", [])
        asks = tick.get("asks", [])
        if not bids or not asks:
            return

        self.best_bid = float(bids[0][0])
        self.best_ask = float(asks[0][0])
        self.mid_price = (self.best_bid + self.best_ask) / 2.0
        self.last_update_ts = now

        # 1. 检测 1 秒内是否发生剧烈跳变 (防套利者捡漏)
        self.short_term_prices.append((now, self.mid_price))
        while self.short_term_prices and now - self.short_term_prices[0][0] > 1.0:
            self.short_term_prices.popleft()

        if len(self.short_term_prices) >= 2:
            oldest_p = self.short_term_prices[0][1]
            pct_move = abs(self.mid_price - oldest_p) / oldest_p
            # 若 1 秒内现货跳变超过 0.12% (12 bps)，触发 3 秒毒性冷却
            if pct_move > 0.0012:
                self.is_toxic_shock = True
                self.toxic_shock_until = now + 3.0

        if self.is_toxic_shock and now > self.toxic_shock_until:
            self.is_toxic_shock = False

        # 2. 每隔 1 秒采样一次用于更新年化波动率
        if not self.price_history or now - self.price_history[-1][0] >= 1.0:
            self.price_history.append((now, math.log(self.mid_price)))
            while (
                self.price_history
                and now - self.price_history[0][0] > self.vol_window_sec
            ):
                self.price_history.popleft()
            self._update_volatility()

    def _update_volatility(self):
        """基于对数收益率计算实时年化波动率"""
        n = len(self.price_history)
        if n < 30:
            return
        returns = [
            self.price_history[i][1] - self.price_history[i - 1][1]
            for i in range(1, n)
        ]
        mean_r = sum(returns) / len(returns)
        var_r = sum((r - mean_r) ** 2 for r in returns) / (len(returns) - 1)
        # 一年约 31,536,000 秒
        inst_vol = math.sqrt(var_r * 31_536_000)
        # 限制波动率合理上下界 (15% ~ 250%) 防止极端插针失真
        self.annual_vol = max(0.15, min(2.50, inst_vol))

    def is_healthy(self) -> bool:
        """检查行情是否新鲜 (超过 1.5 秒无推送视为断流)"""
        return (
            self.mid_price > 0
            and (time.time() - self.last_update_ts) < 1.5
            and not self.is_toxic_shock
        )

    """
    Polymarket Up/Down 盘专用 GLFT 稳态报价求解器
    特性：
    1. 将 OKX 连续价格 S_t 映射为二元数字期权公允概率 P_fair
    2. 推导概率空间动态波动率 sigma_P，临近交割自动放大风险厌恶
    3. 结合 Polymarket Liquidity Rewards 的 MaxSpread 进行区间钳位，兼顾吃奖励与防击穿
    """

    def __init__(
        self,
        gamma: float = 0.15,          # 风险厌恶系数
        k_decay: float = 150.0,       # 订单到达率指数衰减系数 (针对 0~1 价格尺度放大)
        a_intensity: float = 2.5,     # 贴近中间价的瞬时成交到达强度
        tick_size: float = 0.01,      # Polymarket 最小价格步长 (通常 0.01 或 0.001)
        max_inventory: float = 100.0, # 单边最大允许净敞口股数 (例如 100 股 ≈ 50 USDC)
        base_size: float = 20.0,      # 基础挂单股数 (需 >= 市场 Min Size)
    ):
        self.gamma = gamma
        self.k_decay = k_decay
        self.a_intensity = a_intensity
        self.tick_size = tick_size
        self.max_inventory = max_inventory
        self.base_size = base_size

    def compute_quotes(
        self,
        spot_price: float,       # OKX 当前现货中间价 S_t
        strike_price: float,     # 本局 Up/Down 开盘基准价 S_0
        tau_sec: float,          # 距离本局结算剩余秒数 (T - t)
        annual_vol: float,       # OKX 实时年化波动率 sigma_S
        net_inventory: float,    # 当前净库存: YES股数 - NO股数
        poly_mid: float,         # Polymarket 当前盘口中间价 (用于对齐奖励圈)
        max_reward_spread: float = 0.02,  # 该市场允许获得奖励的最大价差 (如 2¢ = 0.02)
    ) -> QuoteOutput:
        # 1. 临近交割硬风控：最后 180 秒Gamma极大，停止做市并准备清仓
        if tau_sec <= 180:
            return QuoteOutput(False, "临近结算(<180s)停止报价", 0.5, 0.0, 0.0, 0.0, 0.0)

        # 年化剩余时间
        tau_years = tau_sec / 31_536_000.0
        vol_sqrt_tau = annual_vol * math.sqrt(tau_years)

        # 2. 二元期权公允概率计算 P_fair = N(d2)
        d2 = (math.log(spot_price / strike_price) - 0.5 * (annual_vol**2) * tau_years) / vol_sqrt_tau
        fair_prob = float(norm.cdf(d2))

        # 3. 过滤边缘概率：偏离 0.50 太远时，加权交易量 P(1-P) 急剧缩水且单边风险高
        if not (0.32 <= fair_prob <= 0.68):
            return QuoteOutput(
                False,
                f"公允概率({fair_prob:.3f})偏离50%核心区",
                fair_prob, 0.0, 0.0, 0.0, 0.0
            )

        # 4. 计算概率空间瞬时波动率 sigma_P = phi(d2) / sqrt(tau)
        # 这里的 tau 采用标准化时间尺度(如小时)避免数值过小
        tau_hours = tau_sec / 3600.0
        sigma_p = float(norm.pdf(d2)) / math.sqrt(max(tau_hours, 0.05))

        # 5. Stationary GLFT 保留价格与最优半利差
        # 库存归一化 [-1, 1]
        q_norm = net_inventory / self.max_inventory
        # 当持仓超过 60% 时，库存惩罚斜率非线性放大 3 倍 (移植自你的 GLFTmm 逻辑)
        inv_multiplier = 3.0 if abs(q_norm) > 0.6 else 1.0

        # 保留概率 r(P, q)
        reservation_prob = fair_prob - q_norm * self.gamma * (sigma_p**2) * 0.05 * inv_multiplier

        # GLFT 稳态半利差 delta_half
        base_spread = (1.0 / self.gamma) * math.log(1.0 + self.gamma / self.k_decay)
        inv_skew = (self.gamma * (sigma_p**2)) / (2.0 * self.k_decay * self.a_intensity)
        delta_half = base_spread + inv_skew

        # 6. Polymarket 流动性挂单奖励钳位 (Reward Clamping)
        # 若 GLFT 算出的安全半利差远大于市场 MaxSpread，说明当前波动过大，放弃本轮报价保本金
        if delta_half > max_reward_spread * 1.5:
            return QuoteOutput(
                False,
                f"波动率过高(delta={delta_half:.4f} > 奖励阈值)，避险撤单",
                fair_prob, sigma_p, 0.0, 0.0, 0.0
            )

        # 正常情况下，将半利差钳位在 [1个Tick, 0.8 * MaxSpread] 之间，确保吃满挂单奖励
        effective_half = max(self.tick_size, min(delta_half, max_reward_spread * 0.8))

        # 计算 YES 侧的理论买卖报价
        raw_bid_yes = reservation_prob - effective_half
        raw_ask_yes = reservation_prob + effective_half

        # 7. 转换为双边纯买单价格 (Buy YES 和 Buy NO)
        # 关键技巧：在 Polymarket 卖出 YES @ P_ask 等价于 买入 NO @ (1 - P_ask)
        bid_yes = self._round_tick(raw_bid_yes, down=True)
        bid_no = self._round_tick(1.0 - raw_ask_yes, down=True)

        # 安全校验：确保 Buy YES + Buy NO < 1.00 (锁定正毛利或保本，绝不倒挂亏钱)
        if bid_yes + bid_no >= 1.0 - self.tick_size:
            bid_no = self._round_tick(1.0 - bid_yes - self.tick_size, down=True)

        # 边界保护
        bid_yes = max(self.tick_size, min(0.98, bid_yes))
        bid_no = max(self.tick_size, min(0.98, bid_no))

        return QuoteOutput(
            should_quote=True,
            reason="OK",
            fair_prob=fair_prob,
            sigma_p=sigma_p,
            bid_yes_price=bid_yes,
            bid_no_price=bid_no,
            order_size=self.base_size,
        )

    def _round_tick(self, price: float, down: bool = True) -> float:
        steps = price / self.tick_size
        rounded = math.floor(steps + 1e-9) if down else math.ceil(steps - 1e-9)
        return round(rounded * self.tick_size, 4)

    调用 Polygon 链上 mergePositions 接口将 min(YES, NO) 瞬间合并换回 USDC，

        self.account = self.w3.eth.account.from_key(private_key)
        self.ctf = self.w3.eth.contract(
            address=Web3.to_checksum_address(CTF_CONTRACT_ADDRESS), abi=CTF_ABI
        )
        self.min_merge_shares = min_merge_shares

    def get_token_balances(self, yes_token_id: int, no_token_id: int) -> tuple[float, float]:
        """查询当前钱包中 YES 与 NO 的实际链上余额 (Polymarket 份额精度为 10^6)"""
        addr = self.account.address
        yes_raw = self.ctf.functions.balanceOf(addr, int(yes_token_id)).call()
        no_raw = self.ctf.functions.balanceOf(addr, int(no_token_id)).call()
        return yes_raw / 1e6, no_raw / 1e6

        self, condition_id_hex: str, yes_token_id: int, no_token_id: int

        返回释放的 USDC 数量

            None, self.get_token_balances, yes_token_id, no_token_id
        )

        if mergeable_shares < self.min_merge_shares:
            return 0.0

        except Exception as e:

            return 0.0

    def _send_merge_tx(self, condition_id_hex: str, amount_raw: int) -> str:
        parent_collection_id = b"\x00" * 32
        condition_id_bytes = bytes.fromhex(condition_id_hex.replace("0x", ""))
        # 二元市场的标准 partition 为 [1, 2]
        partition = [1, 2]

        nonce = self.w3.eth.get_transaction_count(self.account.address)
        tx = self.ctf.functions.mergePositions(
            Web3.to_checksum_address(USDC_COLLATERAL_ADDRESS),
            parent_collection_id,
            condition_id_bytes,
            partition,
            amount_raw,
        ).build_transaction(
            {
                "from": self.account.address,
                "nonce": nonce,
                "gas": 180_000,
                "maxFeePerGas": self.w3.eth.gas_price * 2,
                "maxPriorityFeePerGas": self.w3.to_wei("35", "gwei"),

        tx_hash = self.w3.eth.send_raw_transaction(signed_tx.raw_transaction)

import asyncio
import json
import math
import time
from collections import deque
import websockets


class OKXSpotOracle:
    """
    OKX 公共行情先验引擎 (无需 API Key / 交易权限)
    职责：
    1. 订阅 OKX 公共频道 bbo-tbt (逐笔最优买卖价) 获取毫秒级中间价
    2. 维护滑动窗口计算实时年化波动率 sigma_S (用于二元期权定价)
    3. 计算短周期价格冲击 (Toxic Jump)，触发 Polymarket 紧急撤单保护
    """

    WS_URL = "wss://://okx.com"

    def __init__(self, inst_id: str = "BTC-USDT", vol_window_sec: int = 300):
        self.inst_id = inst_id
        self.vol_window_sec = vol_window_sec

        # 实时价格状态
        self.best_bid: float = 0.0
        self.best_ask: float = 0.0
        self.mid_price: float = 0.0
        self.last_update_ts: float = 0.0

        # 用于计算波动率的采样队列: 存储 (timestamp, log_price)
        self.price_history: deque = deque()
        # 默认初始年化波动率 (例如 BTC 50%)
        self.annual_vol: float = 0.50

        # 毒性跳变检测 (1秒内涨跌幅超过阈值则标记为毒性冲击)
        self.short_term_prices: deque = deque()
        self.is_toxic_shock: bool = False
        self.toxic_shock_until: float = 0.0

    async def start(self):
        """启动后台 WebSocket 断线重连循环"""
        while True:
            try:
                async with websockets.connect(
                    self.WS_URL, ping_interval=20, ping_timeout=10
                ) as ws:
                    sub_msg = {
                        "op": "subscribe",
                        "args": [{"channel": "bbo-tbt", "instId": self.inst_id}],
                    }
                    await ws.send(json.dumps(sub_msg))
                    print(f"[OKXOracle] 已连接并订阅公共行情: {self.inst_id}")

                    async for raw_msg in ws:
                        if raw_msg == "pong":
                            continue
                        data = json.loads(raw_msg)
                        if "data" in data and len(data["data"]) > 0:
                            self._on_bbo_tick(data["data"][0])

            except Exception as e:
                print(f"[OKXOracle] 连接断开 ({e})，2秒后重连...")
                await asyncio.sleep(2)

    def _on_bbo_tick(self, tick: dict):
        """处理逐笔 BBO 数据"""
        now = time.time()
        bids = tick.get("bids", [])
        asks = tick.get("asks", [])
        if not bids or not asks:
            return

        self.best_bid = float(bids[0][0])
        self.best_ask = float(asks[0][0])
        self.mid_price = (self.best_bid + self.best_ask) / 2.0
        self.last_update_ts = now

        # 1. 检测 1 秒内是否发生剧烈跳变 (防套利者捡漏)
        self.short_term_prices.append((now, self.mid_price))
        while self.short_term_prices and now - self.short_term_prices[0][0] > 1.0:
            self.short_term_prices.popleft()

        if len(self.short_term_prices) >= 2:
            oldest_p = self.short_term_prices[0][1]
            pct_move = abs(self.mid_price - oldest_p) / oldest_p
            # 若 1 秒内现货跳变超过 0.12% (12 bps)，触发 3 秒毒性冷却
            if pct_move > 0.0012:
                self.is_toxic_shock = True
                self.toxic_shock_until = now + 3.0

        if self.is_toxic_shock and now > self.toxic_shock_until:
            self.is_toxic_shock = False

        # 2. 每隔 1 秒采样一次用于更新年化波动率
        if not self.price_history or now - self.price_history[-1][0] >= 1.0:
            self.price_history.append((now, math.log(self.mid_price)))
            while (
                self.price_history
                and now - self.price_history[0][0] > self.vol_window_sec
            ):
                self.price_history.popleft()
            self._update_volatility()

    def _update_volatility(self):
        """基于对数收益率计算实时年化波动率"""
        n = len(self.price_history)
        if n < 30:
            return
        returns = [
            self.price_history[i][1] - self.price_history[i - 1][1]
            for i in range(1, n)
        ]
        mean_r = sum(returns) / len(returns)
        var_r = sum((r - mean_r) ** 2 for r in returns) / (len(returns) - 1)
        # 一年约 31,536,000 秒
        inst_vol = math.sqrt(var_r * 31_536_000)
        # 限制波动率合理上下界 (15% ~ 250%) 防止极端插针失真
        self.annual_vol = max(0.15, min(2.50, inst_vol))

    def is_healthy(self) -> bool:
        """检查行情是否新鲜 (超过 1.5 秒无推送视为断流)"""
        return (
            self.mid_price > 0
            and (time.time() - self.last_update_ts) < 1.5
            and not self.is_toxic_shock
        )

        # 这里的 tau 采用标准化时间尺度(如小时)避免数值过小
        tau_hours = tau_sec / 3600.0
        sigma_p = float(norm.pdf(d2)) / math.sqrt(max(tau_hours, 0.05))

        # 5. Stationary GLFT 保留价格与最优半利差
        # 库存归一化 [-1, 1]
        q_norm = net_inventory / self.max_inventory
        # 当持仓超过 60% 时，库存惩罚斜率非线性放大 3 倍 (移植自你的 GLFTmm 逻辑)
        inv_multiplier = 3.0 if abs(q_norm) > 0.6 else 1.0

        # 保留概率 r(P, q)
        reservation_prob = fair_prob - q_norm * self.gamma * (sigma_p**2) * 0.05 * inv_multiplier

        # GLFT 稳态半利差 delta_half
        base_spread = (1.0 / self.gamma) * math.log(1.0 + self.gamma / self.k_decay)
        inv_skew = (self.gamma * (sigma_p**2)) / (2.0 * self.k_decay * self.a_intensity)
        delta_half = base_spread + inv_skew

        # 6. Polymarket 流动性挂单奖励钳位 (Reward Clamping)
        # 若 GLFT 算出的安全半利差远大于市场 MaxSpread，说明当前波动过大，放弃本轮报价保本金
        if delta_half > max_reward_spread * 1.5:
            return QuoteOutput(
                False,
                f"波动率过高(delta={delta_half:.4f} > 奖励阈值)，避险撤单",
                fair_prob, sigma_p, 0.0, 0.0, 0.0
            )

        # 正常情况下，将半利差钳位在 [1个Tick, 0.8 * MaxSpread] 之间，确保吃满挂单奖励
        effective_half = max(self.tick_size, min(delta_half, max_reward_spread * 0.8))

        # 计算 YES 侧的理论买卖报价
        raw_bid_yes = reservation_prob - effective_half
        raw_ask_yes = reservation_prob + effective_half

        # 7. 转换为双边纯买单价格 (Buy YES 和 Buy NO)
        # 关键技巧：在 Polymarket 卖出 YES @ P_ask 等价于 买入 NO @ (1 - P_ask)
        bid_yes = self._round_tick(raw_bid_yes, down=True)
        bid_no = self._round_tick(1.0 - raw_ask_yes, down=True)

        # 安全校验：确保 Buy YES + Buy NO < 1.00 (锁定正毛利或保本，绝不倒挂亏钱)
        if bid_yes + bid_no >= 1.0 - self.tick_size:
            bid_no = self._round_tick(1.0 - bid_yes - self.tick_size, down=True)

        # 边界保护
        bid_yes = max(self.tick_size, min(0.98, bid_yes))
        bid_no = max(self.tick_size, min(0.98, bid_no))

        return QuoteOutput(
            should_quote=True,
            reason="OK",
            fair_prob=fair_prob,
            sigma_p=sigma_p,
            bid_yes_price=bid_yes,
            bid_no_price=bid_no,
            order_size=self.base_size,
        )

    def _round_tick(self, price: float, down: bool = True) -> float:
        steps = price / self.tick_size
        rounded = math.floor(steps + 1e-9) if down else math.ceil(steps - 1e-9)
        return round(rounded * self.tick_size, 4)

class CTFAutoMerger:
    """
    Polymarket 资金效率倍增器：
    当双边挂单均成交后，钱包同时持有 YES 和 NO 代币。
    调用 Polygon 链上 mergePositions 接口将 min(YES, NO) 瞬间合并换回 USDC，
    无需等待到期结算，实现 1,400 U 小资金无限次高频循环刷量。

    def __init__(self, rpc_url: str, private_key: str, min_merge_shares: float = 10.0):
        self.w3 = Web3(Web3.HTTPProvider(rpc_url))
        self.account = self.w3.eth.account.from_key(private_key)
        self.ctf = self.w3.eth.contract(
            address=Web3.to_checksum_address(CTF_CONTRACT_ADDRESS), abi=CTF_ABI
        )
        self.min_merge_shares = min_merge_shares

    def get_token_balances(self, yes_token_id: int, no_token_id: int) -> tuple[float, float]:
        """查询当前钱包中 YES 与 NO 的实际链上余额 (Polymarket 份额精度为 10^6)"""
        addr = self.account.address
        yes_raw = self.ctf.functions.balanceOf(addr, int(yes_token_id)).call()
        no_raw = self.ctf.functions.balanceOf(addr, int(no_token_id)).call()
        return yes_raw / 1e6, no_raw / 1e6

    async def check_and_merge(
        self, condition_id_hex: str, yes_token_id: int, no_token_id: int
    ) -> float:

        检查是否满足合仓条件，若 min(YES, NO) >= min_merge_shares 则发起链上 Merge
        返回释放的 USDC 数量

            None, self.get_token_balances, yes_token_id, no_token_id
        )

        if mergeable_shares < self.min_merge_shares:
            return 0.0

        # 向下取整保留 2 位小数精度转换为 1e6 整数

            )

            return amount_raw / 1e6
        except Exception as e:
            print(f"[CTFMerger] 合仓交易失败: {e}")
            return 0.0

    def _send_merge_tx(self, condition_id_hex: str, amount_raw: int) -> str:

            Web3.to_checksum_address(USDC_COLLATERAL_ADDRESS),
            parent_collection_id,
            condition_id_bytes,

            amount_raw,

            {

                "nonce": nonce,
                "gas": 180_000,

import asyncio
import time
from py_clob_client.client import ClobClient
from py_clob_client.clob_types import OrderArgs, OrderType, PostOrdersArgs
from py_clob_client.order_builder.constants import BUY

from okx_spot_oracle import OKXSpotOracle
from binary_glft_pricer import BinaryGLFTPricer
from ctf_auto_merger import CTFAutoMerger


class PolymarketUpDownMMRunner:
    """
    Polymarket Up/Down 做市主控循环
    核心机制：
    1. 强制 Post-Only 挂单，零 Taker 手续费损耗
    2. 批量改单 (cancel_all + post_orders) 维持盘口中间价奖励得分
    3. 定时触发 CTF Merge 回收 USDC，支持单边库存超限减仓
    """

    def __init__(
        self,
        clob_client: ClobClient,
        oracle: OKXSpotOracle,
        pricer: BinaryGLFTPricer,
        merger: CTFAutoMerger,
        market_cfg: dict,
    ):
        self.client = clob_client
        self.oracle = oracle
        self.pricer = pricer
        self.merger = merger
        self.cfg = market_cfg

        # 当前挂单状态缓存
        self.last_bid_yes: float = 0.0
        self.last_bid_no: float = 0.0
        self.last_merge_ts: float = 0.0
        self.is_running: bool = True

    async def run(self):
        # 并发启动 OKX 行情订阅 与 做市主循环
        await asyncio.gather(
            self.oracle.start(),
            self._market_making_loop(),
            self._heartbeat_loop(),
        )

    async def _heartbeat_loop(self):
        """
        Polymarket 死开关保活 (Heartbeat)：
        若本地进程卡死或断网，Polymarket 服务器会在超时后自动撤销所有挂单，防止极端行情裸奔
        """
        while self.is_running:
            try:
                # 实际使用中可调用 client.post_heartbeat() (视 py-clob-client 版本)
                pass
            except Exception as e:
                print(f"[Heartbeat] 异常: {e}")
            await asyncio.sleep(5)

    async def _market_making_loop(self):
        yes_token = self.cfg["yes_token_id"]
        no_token = self.cfg["no_token_id"]
        condition_id = self.cfg["condition_id"]
        strike_price = self.cfg["strike_price"]
        expiry_ts = self.cfg["expiry_ts"]
        max_reward_spread = self.cfg.get("max_reward_spread", 0.02)

        print(f"[MMRunner] 启动市场做市: {self.cfg['question']} | 基准价: {strike_price}")

        while self.is_running:
            now = time.time()
            tau_sec = expiry_ts - now

            # 1. 市场已到期则结束本场循环
            if tau_sec <= 0:
                print("[MMRunner] 本场 Up/Down 已到期结算，退出循环。")
                await self._cancel_all_safe()
                break

            # 2. 检查 OKX 先验行情是否健康 (若发生 1s 剧烈跳变或断流，立即撤单避险)
            if not self.oracle.is_healthy():
                if self.last_bid_yes > 0 or self.last_bid_no > 0:
                    print("[MMRunner] 触发 OKX 毒性行情/断流保护，紧急撤销全部挂单！")
                    await self._cancel_all_safe()
                await asyncio.sleep(0.2)
                continue

            # 3. 查询当前链上双边持仓，计算净库存并触发周期性合仓
            yes_bal, no_bal = self.merger.get_token_balances(int(yes_token), int(no_token))
            net_inventory = yes_bal - no_bal

            if now - self.last_merge_ts > 15.0:
                self.last_merge_ts = now
                released = await self.merger.check_and_merge(
                    condition_id, int(yes_token), int(no_token)
                )
                if released > 0:
                    yes_bal -= released
                    no_bal -= released
                    net_inventory = yes_bal - no_bal

            # 4. 获取 Polymarket 当前盘口中间价 (用于奖励区间对齐)
            poly_mid = self._get_poly_midpoint(yes_token)

            # 5. 调用二元期权 GLFT 定价器计算最优双边买价
            quote = self.pricer.compute_quotes(
                spot_price=self.oracle.mid_price,
                strike_price=strike_price,
                tau_sec=tau_sec,
                annual_vol=self.oracle.annual_vol,
                net_inventory=net_inventory,
                poly_mid=poly_mid,
                max_reward_spread=max_reward_spread,
            )

            if not quote.should_quote:
                if self.last_bid_yes > 0 or self.last_bid_no > 0:
                    print(f"[MMRunner] 暂停报价 ({quote.reason})，撤销挂单。")
                    await self._cancel_all_safe()
                await asyncio.sleep(1.0)
                continue

            # 6. 仅当新报价与当前挂单价格发生变化时才发送改单指令 (节省 API 频控)
            if (
                abs(quote.bid_yes_price - self.last_bid_yes) >= 1e-4
                or abs(quote.bid_no_price - self.last_bid_no) >= 1e-4
            ):
                await self._refresh_two_sided_quotes(
                    yes_token=yes_token,
                    no_token=no_token,
                    bid_yes=quote.bid_yes_price,
                    bid_no=quote.bid_no_price,
                    size=quote.order_size,
                    net_inventory=net_inventory,
                )

            # 控制主循环频率 (每 400ms 评估一次)
            await asyncio.sleep(0.4)

    def _get_poly_midpoint(self, token_id: str) -> float:
        try:
            mid_resp = self.client.get_midpoint(token_id)
            return float(mid_resp.get("mid", 0.5))
        except Exception:
            return 0.5

    async def _cancel_all_safe(self):
        loop = asyncio.get_running_loop()
        try:
            await loop.run_in_executor(None, self.client.cancel_all)
            self.last_bid_yes = 0.0
            self.last_bid_no = 0.0
        except Exception as e:
            print(f"[MMRunner] 撤单异常: {e}")

    async def _refresh_two_sided_quotes(
        self,
        yes_token: str,
        no_token: str,
        bid_yes: float,
        bid_no: float,
        size: float,
        net_inventory: float,
    ):
        """
        先撤旧单，再批量提交双边 Post-Only 买单
        若单边库存过高，则只挂反向单进行去库存 (Reduce-Only 思维)
        """
        loop = asyncio.get_running_loop()
        await self._cancel_all_safe()

        orders_to_post = []

        # 如果 YES 净多头未超限，允许继续挂 Buy YES
        if net_inventory < self.pricer.max_inventory * 0.8:
            yes_order = self.client.create_order(
                OrderArgs(
                    price=bid_yes,
                    size=size,
                    side=BUY,
                    token_id=yes_token,
                )
            )
            orders_to_post.append(
                PostOrdersArgs(
                    order=yes_order,
                    orderType=OrderType.GTC,
                    postOnly=True,  # 强制纯 Maker，若会立即成交则被交易所拒绝
                )
            )

        # 如果 NO 净多头未超限，允许继续挂 Buy NO
        if net_inventory > -self.pricer.max_inventory * 0.8:
            no_order = self.client.create_order(
                OrderArgs(
                    price=bid_no,
                    size=size,
                    side=BUY,
                    token_id=no_token,
                )
            )
            orders_to_post.append(
                PostOrdersArgs(
                    order=no_order,
                    orderType=OrderType.GTC,
                    postOnly=True,
                )
            )

        if not orders_to_post:
            return

        try:
            await loop.run_in_executor(None, self.client.post_orders, orders_to_post)
            self.last_bid_yes = bid_yes if net_inventory < self.pricer.max_inventory * 0.8 else 0.0
            self.last_bid_no = bid_no if net_inventory > -self.pricer.max_inventory * 0.8 else 0.0
            print(
                f"[Quote] OKX={self.oracle.mid_price:.1f} | "
                f"BuyYES={self.last_bid_yes:.3f} | BuyNO={self.last_bid_no:.3f} | "
                f"NetInv={net_inventory:.1f}"
            )
        except Exception as e:
            print(f"[MMRunner] 批量下单失败: {e}")

1. 代理钱包（Proxy Wallet）的 Merge 权限注意：
    • 如果你的 Polymarket 账号是通过 MetaMask / Rabby 插件直连（EOA 钱包，signature_type=0） 注册的，上述 CTFAutoMerger 可直接用私钥调用链上 mergePositions 合并持仓。
    • 如果你是通过 邮箱 / Google 登录（Proxy Wallet，signature_type=1） 注册的，资金存放在 Polymarket 为你创建的 Gnosis Safe 代理合约里，直接用 EOA 私钥调 mergePositions 会提示余额为 0——此时只需改用 Polymarket 官方 Relayer 提供的无 Gas merge 签名接口，或新建一个 EOA 直连钱包专门跑量化（强烈推荐后者，EOA 钱包完全自主掌控私钥且无需额外中继签名）。

    Polymarket Gamma API 自动抓盘引擎
    职责：
    1. 自动发现当前或下一场即将开盘的 Crypto 15m / 1h Up/Down 市场
    2. 提取 condition_id, yes_token_id, no_token_id, tick_size, expiry_ts
    3. 结合 CLOB API 获取最新的流动性奖励参数 (max_reward_spread, min_size)
    4. 配合 OKX 实时价格在开盘瞬间锁定基准价 (Strike Price S_0)
    """

    GAMMA_EVENTS_URL = "https://polymarket.com"
    GAMMA_MARKETS_URL = "https://polymarket.com"

    def __init__(self, clob_client: ClobClient | None = None):
        self.clob_client = clob_client

    @staticmethod
    def get_current_and_next_15m_timestamps() -> list[int]:
        """
        计算当前15分钟场次与下一场15分钟场次的整点结算/开盘 Unix 时间戳
        Polymarket 15m Up/Down 盘的 slug 通常包含该场次的 Unix 时间戳
        例如: btc-updown-15m-1732111200
        """
        now = int(time.time())
        interval = 900  # 15分钟 = 900秒
        current_slot = (now // interval) * interval
        return [current_slot, current_slot + interval, current_slot + 2 * interval]

    @staticmethod
    def get_current_and_next_1h_timestamps() -> list[int]:
        """计算当前1小时场次与下一场1小时场次的整点 Unix 时间戳"""
        now = int(time.time())
        interval = 3600
        current_slot = (now // interval) * interval
        return [current_slot, current_slot + interval]

    async def fetch_market_by_slug(self, session: aiohttp.ClientSession, slug: str) -> dict | None:
        """通过精确 slug 查询 Gamma API 事件详情"""
        params = {"slug": slug}
        try:
            async with session.get(self.GAMMA_EVENTS_URL, params=params, timeout=8) as resp:
                if resp.status != 200:
                    return None
                data = await resp.json()
                if isinstance(data, list) and len(data) > 0:
                    return data[0]
        except Exception as e:
            print(f"[GammaScanner] 查询 slug={slug} 异常: {e}")
        return None

    async def search_active_updown_markets(
        self,
        session: aiohttp.ClientSession,
        asset_prefix: str = "btc",       # 支持 "btc", "eth", "sol"
        timeframe: str = "15m",          # 支持 "15m", "1h"
        min_remaining_sec: int = 240,    # 至少还剩 4 分钟才考虑接盘，避免刚进去就面临交割
    ) -> dict | None:
        """
        自动抓取最适合当前做市的活跃 Up/Down 场次
        返回可直接传给 PolymarketUpDownMMRunner 的标准化配置字典
        """
        slots = (
            self.get_current_and_next_15m_timestamps()
            if timeframe == "15m"
            else self.get_current_and_next_1h_timestamps()
        )

        # 1. 优先通过规律构造的 slug 精确匹配 (速度最快、无分页延迟)
        for ts in slots:
            slug = f"{asset_prefix.lower()}-updown-{timeframe}-{ts}"
            event = await self.fetch_market_by_slug(session, slug)
            if event:
                parsed = self._parse_event_to_config(event, min_remaining_sec)
                if parsed:
                    return parsed

        # 2. 兜底方案：若官方变更了 slug 命名格式，按活跃状态与关键词扫描 Gamma 市场列表
        params = {
            "active": "true",
            "closed": "false",
            "limit": 50,
            "order": "endDate",
            "ascending": "true",
        }
        try:
            async with session.get(self.GAMMA_EVENTS_URL, params=params, timeout=10) as resp:
                if resp.status == 200:
                    events = await resp.json()
                    keyword_asset = {"btc": "bitcoin", "eth": "ethereum", "sol": "solana"}.get(
                        asset_prefix.lower(), asset_prefix.lower()
                    )
                    for ev in events:
                        title = ev.get("title", "").lower()
                        if keyword_asset in title and "up or down" in title:
                            parsed = self._parse_event_to_config(ev, min_remaining_sec)
                            if parsed:
                                return parsed
        except Exception as e:
            print(f"[GammaScanner] 兜底列表扫描异常: {e}")

        return None

    def _parse_event_to_config(self, event: dict, min_remaining_sec: int) -> dict | None:
        """解析 Gamma Event JSON，提取交易与奖励核心参数"""
        markets = event.get("markets", [])
        if not markets:
            return None

        mkt = markets[0]
        if mkt.get("closed") or not mkt.get("active"):
            return None

        # 解析到期时间 (ISO-8601 格式转为 Unix 时间戳)
        end_date_str = mkt.get("endDate") or event.get("endDate")
        if not end_date_str:
            return None
        expiry_dt = datetime.fromisoformat(end_date_str.replace("Z", "+00:00"))
        expiry_ts = expiry_dt.timestamp()

        now = time.time()
        remaining = expiry_ts - now
        if remaining < min_remaining_sec:
            return None

        # 解析 clobTokenIds (Gamma API 返回的通常是 JSON 字符串，如 '["123...", "456..."]')
        raw_tokens = mkt.get("clobTokenIds", "[]")
        token_ids = json.loads(raw_tokens) if isinstance(raw_tokens, str) else raw_tokens
        if len(token_ids) < 2:
            return None

        # 解析 outcomes 确认哪个是 Up(YES)，哪个是 Down(NO)
        raw_outcomes = mkt.get("outcomes", '["Up", "Down"]')
        outcomes = json.loads(raw_outcomes) if isinstance(raw_outcomes, str) else raw_outcomes

        yes_idx = 0
        no_idx = 1
        for i, name in enumerate(outcomes):
            if str(name).lower() in ("up", "yes"):
                yes_idx = i
            elif str(name).lower() in ("down", "no"):
                no_idx = i

        yes_token_id = str(token_ids[yes_idx])
        no_token_id = str(token_ids[no_idx])
        condition_id = mkt.get("conditionId", "")
        tick_size = float(mkt.get("orderPriceMinTickSize", 0.01))

        # 提取流动性奖励参数 (若 Gamma 字段缺失，则通过 CLOB API 实时补全)
        max_reward_spread = float(mkt.get("rewardsMaxSpread", 0.0) or 0.0)
        min_reward_size = float(mkt.get("rewardsMinSize", 0.0) or 0.0)

        if (max_reward_spread <= 0 or min_reward_size <= 0) and self.clob_client:
            try:
                clob_mkt = self.clob_client.get_market(condition_id)
                rewards_cfg = clob_mkt.get("rewards", {})
                if rewards_cfg:
                    max_reward_spread = float(rewards_cfg.get("max_spread", 0.02))
                    min_reward_size = float(rewards_cfg.get("min_size", 5.0))
            except Exception:
                pass

        # 若仍未获取到，给予保守默认值 (2美分价差，最小10股)
        if max_reward_spread <= 0:
            max_reward_spread = 0.02
        if min_reward_size <= 0:
            min_reward_size = 10.0

        # 计算开盘时间 (15m盘为到期前900s，1h盘为到期前3600s)
        start_date_str = mkt.get("eventStartTime") or mkt.get("startDate")
        if start_date_str:
            start_ts = datetime.fromisoformat(start_date_str.replace("Z", "+00:00")).timestamp()
        else:
            start_ts = expiry_ts - 900

        return {
            "question": mkt.get("question", event.get("title", "Unknown Up/Down")),
            "slug": event.get("slug", ""),
            "condition_id": condition_id,
            "yes_token_id": yes_token_id,
            "no_token_id": no_token_id,
            "tick_size": tick_size,
            "start_ts": start_ts,
            "expiry_ts": expiry_ts,
            "max_reward_spread": max_reward_spread,
            "min_reward_size": min_reward_size,
            "strike_price": None,  # 需在开盘瞬间由 OKX Oracle 填充
        }

async def auto_scheduler_loop(oracle, clob_client, pricer, merger, runner_cls):
    """
    7x24小时自动轮换调度器：
    1. 自动发现下一场即将开盘的 BTC 15m Up/Down 市场
    2. 精准等待到该场开盘那一秒，截取 OKX 现货中间价作为基准价 S_0
    3. 启动做市引擎直到本场到期，随后无缝切换下一场
    """
    scanner = PolymarketGammaScanner(clob_client=clob_client)

    async with aiohttp.ClientSession() as session:
        while True:
            print("\n[Scheduler] 正在扫描下一场可做市的 BTC 15m Up/Down 盘口...")
            market_cfg = await scanner.search_active_updown_markets(
                session=session,
                asset_prefix="btc",
                timeframe="15m",
                min_remaining_sec=300,  # 至少剩5分钟才接入
            )

            if not market_cfg:
                print("[Scheduler] 暂未发现符合条件的场次，10秒后重试...")
                await asyncio.sleep(10)
                continue

            now = time.time()
            start_ts = market_cfg["start_ts"]

            # 情况 A：场次尚未开盘，精准等待至开盘第 0 秒截取基准价 S_0
            if start_ts > now:
                wait_sec = start_ts - now
                print(
                    f"[Scheduler] 锁定目标场次: {market_cfg['question']} | "
                    f"将在 {wait_sec:.1f} 秒后开盘..."
                )
                await asyncio.sleep(wait_sec)

                # 确保 OKX 行情健康并锁定开盘基准价 S_0
                while oracle.mid_price <= 0:
                    await asyncio.sleep(0.05)
                market_cfg["strike_price"] = oracle.mid_price
                print(f"[Scheduler] 开盘瞬间锁定基准价 Strike S_0 = {market_cfg['strike_price']:.2f}")

            # 情况 B：场次已经开盘中途接入，通过当前 Polymarket 中间价反推等效基准价 S_0
            else:
                while oracle.mid_price <= 0:
                    await asyncio.sleep(0.05)
                # 若中途接入，用当前 OKX 价格近似初始化 (建议尽量提前等待下一场开盘，基准价更精准)
                market_cfg["strike_price"] = oracle.mid_price
                print(
                    f"[Scheduler] 中途接入场次: {market_cfg['question']} | "
                    f"剩余 {market_cfg['expiry_ts'] - time.time():.0f}s | 参考价 = {market_cfg['strike_price']:.2f}"
                )

            # 动态对齐该市场的 tick_size 与最小奖励挂单量
            pricer.tick_size = market_cfg["tick_size"]
            pricer.base_size = max(pricer.base_size, market_cfg["min_reward_size"])

            # 启动本场做市主循环 (当本场到期后 run_single_market 会自动返回)
            runner = runner_cls(clob_client, oracle, pricer, merger, market_cfg)
            await runner._market_making_loop()

### 实战串联注意细节

1. **为什么 `auto_scheduler_loop` 强烈建议提前等待“下一场整点开盘”？**
   * Up/Down 盘的结算规则严格判定的是 **`开盘那一秒的基准价 S₀`** 与 **`收盘那一秒的结算价 S_T`** 的大小。
   * 如果你在 15 分钟盘已经走了 7 分钟后中途接入，此时市场价格可能已经涨了 0.3%，你拿当时的 OKX 价格当 S₀ 会导致计算出的公允概率偏离真实盘口。因此脚本里把 `min_remaining_sec` 设为 `300` 以上时，若当前场次快结束了，它会自动跳过当前场次，**提前几分钟锁定下一场整点/刻钟场次，并在开盘第 0.0 秒精准记录 `oracle.mid_price` 作为真正的 S₀**，这样你的二元期权定价模型在整个 15 分钟周期内都是 100% 精确对齐的。
2. **后台常驻运行结构：**
   * 在主入口文件中，把 `oracle.start()` 作为一个独立后台 Task 永久运行，然后并行启动 2～3 个 `auto_scheduler_loop`（分别跑 `btc` 15m、`eth` 15m、`sol` 15m），即可实现 1,400 U 本金切分多仓位、7×24 小时无人值守自动切场挂单吃奖励与刷返点。
